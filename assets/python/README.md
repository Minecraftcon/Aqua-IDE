# Aqua Python Assets

Prebuilt Python packages for Aqua live here.

Current layout:

- `debs/<arch>/`: Termux-style `.deb` packages containing Python modules.
- `wheels/<arch>/`: Python wheels that should appear in Aqua's GitHub Pages
  pip index before PyPI fallback.

Future layout can add:

- `simple/`: PEP 503-style pip index pages.
