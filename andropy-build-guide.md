
# Aqua IDE - Android IDE

## Overview
Aqua IDE is a minimal-design Android development IDE with Python, terminal, and native-tooling support.

## Features

### Python Development
- Latest CPython version support
- Integrated Python build tools
- Package management and virtual environments

### C++ Development
- Full C++ toolchain integration
- NDK support for native development
- Code completion and debugging

### Build Tools
- Gradle integration
- APK compilation and signing
- Emulator and device deployment

### Design
- Clean, minimal user interface
- Dark mode support
- Fast performance
- Intuitive project navigation

## Getting Started
1. Install AndroPy
2. Create a new project (Python, C++, or hybrid)
3. Configure build settings
4. Deploy to device or emulator

## System Requirements
- Python 3.10+
- Android SDK/NDK
- 4GB+ RAM recommended
